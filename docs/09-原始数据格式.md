# 采集 schema（国内主流视频平台 · 全分区全兴趣向）

目标规模：约 100 万条记录，分三类。所有文件 UTF-8、JSONL、一行一条、无 BOM。**不许编造任何字段**，拿不到就 `null` 并在 summary 的 `failed` 里写原因。

## 一、`raw\bili-meta-*.jsonl` —— B站视频元数据（主力，目标 ≥ 80 万条去重）

```json
{
  "platform": "bilibili",
  "bvid": "BV1xx411c7mD",
  "aid": 123456,
  "title": "原样标题，不做清理",
  "tname": "单机游戏",
  "tid": 17,
  "partition_path": "游戏/单机游戏",
  "keyword": "用来搜到它的关键词",
  "source": "search | ranking | popular | related",
  "tags": ["原神", "实况"],
  "author_mid": 12345,
  "author_name": "某某UP",
  "pubdate": 1730000000,
  "duration_s": 754,
  "stat": {"view": 12345, "danmaku": 88, "reply": 9, "favorite": 66, "coin": 5, "like": 100, "share": 2},
  "desc_len": 120,
  "url": "https://www.bilibili.com/video/BV1xx411c7mD",
  "crawled_at": "2026-11-24T05:10:00+08:00"
}
```

- `bvid` 是主键，全库必须去重（同一视频多次出现只留一条，`source` 保留首次来源）。
- `tags` 允许空数组，**不要用标题猜标签**；只有真从 `view`/`tag/archive/tags` 接口拿到才写。
- `partition_path` 用 `/` 拼接，来自分区树或 `typename` 的反查，不确定就写 `null`。

## 二、`raw\bili-text.jsonl` —— B站文本（弹幕 + 评论，目标 ≥ 30 万条）

弹幕：
```json
{"platform":"bilibili","kind":"danmaku","bvid":"BV1xx","cid":111,"tname":"单机游戏",
 "text":"原样弹幕文本","time_ms":12500,"mode":1,"color":16777215,
 "video_pubdate":1730000000,"crawled_at":"..."}
```

评论（含楼中楼）：
```json
{"platform":"bilibili","kind":"reply","bvid":"BV1xx","rpid":123,"root":0,"parent":0,
 "depth":0,"text":"原样评论文本","likes":12,"ctime":1730000100,"uid":123456,
 "tname":"单机游戏","crawled_at":"..."}
```

## 三、`raw\other-meta.jsonl` —— 其它平台（抖音/快手/西瓜/优酷/腾讯视频/爱奇艺/微博视频，目标 ≥ 5 万条）

```json
{
  "platform": "douyin | kuaishou | ixigua | youku | qqvideo | iqiyi | weibo",
  "item_id": "平台自有 id",
  "title": "原样",
  "category": "平台自己的分区/频道名，拿不到就 null",
  "interest": ["推断的兴趣标签，只在有真实来源时写"],
  "author": "作者名，可为 null",
  "publish_ts": 1730000000,
  "duration_s": 60,
  "stat": {"view": null, "like": null, "comment": null},
  "url": "原链接",
  "source": "哪个入口拿到的（榜单名/搜索关键词/API 名）",
  "crawled_at": "..."
}
```

## 四、汇总文件

每个采集器写 `raw\_summary_<name>.json`：

```json
{"name":"bili-meta","records":812345,"files":["bili-meta-001.jsonl"],"by_source":{...},
 "by_tname":{"游戏":12345},"failed":[{"source":"...","reason":"..."}],"notes":["口径说明"]}
```

## 五、硬要求

1. **限速**：同一域名 ≤ 8 请求/秒、并发 ≤ 4，遇 412/429 退避 30 秒并降速；不要用浏览器工具。
2. **不编造**：字段拿不到写 `null`；不要把英文标题机翻；不要补造标签。
3. **中文保留原文**：`text` 不要过滤表情、颜文字、重复字符。
4. **脱敏**：手机号、邮箱、身份证号、QQ 号 → `<已隐去>`。
5. 每个文件 ≤ 200 MB，超了换下一个编号。
