## 怎么读

- 弹幕是「边看边喊」，所以 ≤8 字占比极高、几乎不写句末标点；评论是「看完再说」，句子明显更长。
- 「笑点标记率」= 含 哈哈/233/hhh/草/笑死 的条数占比，「叠字率」= 含 3 个以上连续同字的条数占比。这两个是最省事的「真人感」指纹。
- 高赞评论里能直接看出该分区的表达习惯（长文分析 / 一句话抖机灵 / 方言吐槽）。
